# PDF fonts

Noto Sans Regular and Noto Sans Math Regular are bundled only for PDF export.
They are licensed under the SIL Open Font License 1.1; see `OFL.txt`.

Source: https://github.com/notofonts/noto-fonts

- https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansMath/NotoSansMath-Regular.ttf

The regular font supplies accented Latin and Greek text; the math font supplies
symbols such as ≤, ≥, √, and ∫. Unsupported characters produce an explicit export
error instead of being removed from the document.
